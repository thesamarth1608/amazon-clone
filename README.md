# 🛒 Amazon Clone

A modern Amazon-inspired eCommerce frontend built using React and Vite.  
This project replicates the core UI and shopping experience of Amazon with responsive design, reusable components, routing, and dynamic product sections.

---

## 🚀 Live Demo

🌐 Live Site: https://amazon-clone-nu-drab.vercel.app


📂 GitHub Repository:  
https://github.com/thesamarth1608/amazon-clone

---

# ✨ Features

- 🏠 Amazon-style Homepage
- 🔍 Product Search UI
- 🛒 Add to Cart Functionality
- 📱 Fully Responsive Design
- ⚡ Fast Performance using Vite
- 🎨 Clean UI with modern styling
- 🔄 Reusable React Components
- 🌐 React Router Navigation
- 📦 Dynamic Product Rendering

## ⚙️ Installation & Setup

## Clone the repository

```bash
git clone https://github.com/thesamarth1608/amazon-clone.git
```

## Navigate to project folder

```bash
cd amazon-clone
```

## Install dependencies

```bash
npm install
```

## Run development server

```bash
npm run dev
```
